## Power Dev Workflow

Use Power Dev Workflow for feature development, material bug fixes, refactors, and architectural changes. Classify work as small, medium, or large and use independent specialist contexts. Only one worker may edit production code at a time. Architecture reviewers, design reviewers, and code reviewers are read-only. QA may edit tests but not production behavior.
