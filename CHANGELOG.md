# Changelog

## Unreleased

- Validate selected execution contracts in generic projects, respect Laravel adapter opt-outs, reject ledger references outside the frozen contract, and install Specification Reviewer during legacy migration.

- Tune the Spec Kit adapter for unlimited material clarification, concrete rule scenarios, and scenario-to-test evidence without additional mandatory review loops.
- Add optional pre-implementation discovery to Test Analyst and preserve upstream Spec Kit commands.

- Replaced unlimited critical-assurance loops with a two-batch, 18-specialist stop-and-replan budget.
- Added an explainable execution-efficiency score based on elapsed/baseline ratio, repeated starts, remediation batches, late findings, and scope drift.
- Separated the specialist that detects a finding from the workflow stage that should have prevented it.
- Added user-approved learning proposals to execution reports; learnings are never applied automatically.
- Blocked repeated whole-scope reviews and new blocker families discovered during final review from starting open-ended correction loops.
- Bound independent approvals to stable scope and implementation checkpoint IDs.
- Prevented directed reviews and partial QA coverage from replacing full independent gates.
- Counted actual remediation batches instead of interpreting the highest round number as the budget usage.
- Froze validation and QA scope before implementation and made blocking findings prove their contractual basis.
- Restricted remediation checks to assigned findings and direct regressions introduced by the remediation delta.
- Added an automatic execution quality and efficiency report to every completion-gate attempt.
- Added adapter-owned, read-only project diagnostics through `toscanini analyze`.
- Added a visible `toscanini verify` preflight for Spec Kit approvals and Laravel Boost policy.
- Added an independent Specification Reviewer specialist.
- Added `toscanini version` to compare the CLI and project installation versions.
- Made the core independent from Laravel and Spec Kit.
- Added opt-in `laravel`, `spec-kit`, and evidence-based `auto` adapters.
- Added per-agent installation controls and community extension packs.
- Added an interactive Node CLI with incremental adapter and agent management.
- Made the current directory the documented and tested default CLI target.
- Added the optional `terminal-ui` adapter and responsive ANSI command center with live Codex App Server thread status.
- Added an independent Test Analyst gate and made QA a code-independent runtime role that validates representative data through the executable UI/API.
- Added a run-scoped deterministic completion gate so missing or stale specialist approvals block completion.
- Required neutral zero-history review contexts and made inherited-context approvals fail the completion gate.
- Expanded community documentation, architecture diagrams, and contribution guidance.

## 0.1.0 - 2026-08-31
