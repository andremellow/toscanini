# Toscanini identity

The mark is a geometric **T** assembled from three connected performers, a central coordination point, and a diagonal conductor's baton.

## Terminal mark

```text
o━━━━◆━━━━o
     ┃  ╱
     o╱

T O S C A N I N I
```

Use `toscanini-mark.txt` in compact terminal surfaces and `toscanini-banner.txt` for welcome screens. The text versions intentionally use only monospaced Unicode characters and require no color to remain recognizable.

## Color

- Ink: `#071B22`
- Signal: `#63F5E2`
- Text: `#EAFDFC`
- Muted: `#6E9CA2`

The symbol must also work in one color. Color communicates state; it is not part of the mark's meaning.
